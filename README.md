# 题匠 · 每日数学试卷

一个本地运行的小学数学每日练习生成器。每天固定生成一套 40 题：10 道个位数乘法、15 道 20 以内加法、15 道 20 以内减法。乘法单独成组，加法和减法混合排列。试卷会保存在 `data/papers.json`，可查看答案或打印。

## 启动

需要 Python 3.9 或更高版本，无需安装第三方依赖。

```bash
python3 app.py
```

浏览器打开 http://127.0.0.1:8000 。服务启动时会确保当天试卷已生成，并在本地午夜生成次日试卷；需要持续自动生成时，运行服务的电脑必须保持开机且进程持续运行。

## 说明

当前版本只负责生成、保存和打印试卷，不会直接发布到公众号。

## 微信小程序版

原生小程序工程位于 `miniprogram/`，使用微信开发者工具导入该目录即可预览。试卷页可在本地导出一页 PDF，预览/保存到手机或转发给微信好友。提交或上传前，请将 `miniprogram/project.config.json` 中的 `touristappid` 替换为自己的小程序 AppID。

512×512 品牌图标位于 `miniprogram/assets/tijiang-icon.png`；正式小程序头像需另行上传到微信公众平台资料页。

直接转发 PDF 需要微信基础库 2.16.1 或更高版本；低版本会提示当前环境不支持文件转发。

小程序在当天首次打开试卷页时生成并缓存试卷，同一设备当天重复打开会保持不变。小程序进入后台后不能保证定时运行；若需要所有用户看到同一套每日试卷或后台自动生成，需要再接入云开发或部署 HTTPS 后端。
